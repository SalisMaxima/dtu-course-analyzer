# Archived build: minimal UI experiment

This is a preserved, loadable build of the minimal UI experiment. It is stored under `docs/archive/minimal-ui/build/` intentionally: it is archived reference material, not the current proposal or recommended extension.

To test it, load the `extension/` folder as an unpacked browser extension. The preferred original UI remains the repository's top-level `extension/` folder on `feature/course-insights-comparison-chrome`.

The archived build retains the red–yellow–green score colors, but the user preferred the original rough style and its imperfections because this redesign felt too “AI generated / artificial.”
